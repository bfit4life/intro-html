# Traction Report — TikTok / Reel Scripts (Archetype Score Hook)

Five ready-to-record scripts, all built around the same psychological hook that makes Myers-Briggs/Enneagram content go viral: people will watch anything that promises to tell them who they are. Each script is 30-45 seconds, filmable on a phone with zero editing skill required beyond basic text overlays (CapCut free tier is enough).

General filming notes:
- Film vertically, in a gym or driveway, basketball in frame.
- Hook in the first 2 seconds — no logo intro, no "hey guys."
- End every video with the same CTA: "Link in bio. Takes 90 seconds. Free."
- Post the quiz link in bio as `[yourdomain]/assessment.html`.
