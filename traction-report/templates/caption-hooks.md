# Caption Hook Formulas — Traction Report

## Hook Formula A — The Verdict Drop
`[Shoe name]. [One-word verdict]. Here's why. 👇`

## Hook Formula B — The Indictment
`Everyone's hyping [shoe]. But nobody's talking about [specific flaw or standout detail].`

## Hook Formula C — The Real Talk
`Wore these for [X] days / sessions. Here's the honest truth.`

---

## Platform CTAs

**YouTube:** Subscribe + comment prompt
**Instagram:** "Drop your take below." / "Sturdy or Not It — you tell me." / "Save this before you cop."
**TikTok:** "Tell me I'm wrong 👇" / "Stitchworthy? Let's go."
**Threads:** End with a debate-inviting question. No hashtags.
